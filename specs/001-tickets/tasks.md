# Tareas — MDA-1

Rama: `MDA-1-tickets`. Referencias: [spec](spec.md), [plan](plan.md) y [constitución](../../constitution.md).

Todas las tareas están pendientes. **CRÍTICA** indica riesgo de acceso/datos o una dependencia que habilita varias tareas; no significa ampliar alcance. Las dependencias son obligatorias. Cada tarea sigue **test → ver fallar → código → verde**: registrar comando y fallo por la regla faltante, implementar lo mínimo y volver a ejecutar el test y la regresión afectada. Las tareas de infraestructura usan checks ejecutables como test. No se necesita implementar funcionalidades futuras para cerrar ninguna tarea.
